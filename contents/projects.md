# Selected Funded Projects

This page summarizes selected funded projects led by Kuan Huang in medical imaging, weakly
supervised learning, and trustworthy artificial intelligence.

## Breast Cancer Detection in Ultrasound Images Using Weakly Supervised Techniques and Multimodal Model

- **Funding:** Students Partnering with Faculty (SpF), Kean University
- **Award year:** 2025
- **Role:** Principal Investigator
- **Award amount:** $11,500

This project develops weakly supervised and multimodal methods for breast cancer detection in
ultrasound images.

## Collaborative Research: CISE MSI: RCBP: SCH: Advancing Breast Cancer Detection in Ultrasound Imaging through Active and Weakly Supervised Learning Techniques

- **Funding:** National Science Foundation, CISE MSI Award #2430746
- **Award year:** 2024
- **Role:** Principal Investigator
- **Award amount:** $203,981

This project advances breast cancer detection in ultrasound imaging through active learning and
weakly supervised learning techniques.

## Weakly Supervised Image Segmentation with Image Level Labels

- **Funding:** CAHSI-Google Institutional Research Program
- **Award year:** 2023
- **Role:** Principal Investigator
- **Award amount:** $80,000, plus $20,000 in Google Cloud Platform credits

This project develops weakly supervised image segmentation methods using image-level labels.

## Deep Learning-Based Breast Ultrasound Image Analysis

- **Funding:** Students Partnering with Faculty (SpF), Kean University
- **Award year:** 2023
- **Role:** Principal Investigator
- **Award amount:** $16,000

This project develops deep learning methods for breast ultrasound image analysis.
